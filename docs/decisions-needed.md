# 사용자 결정이 필요한 항목

자율 작업 중 사용자 판단 없이 정하면 안 되는 것을 모았다. 각 항목은 **지금 동작(임시 기본값)** 과
**선택지**, **추천** 을 적었다. 결정하면 해당 항목에 결과를 적고 구현한다.

---

## Q1. 추적 시작일 이전 건을 화면에 흐리게 남길지, 감출지

- 근거: 웹 명세 "시안에서 확정되지 않은 것", AC-W56
- 지금 동작: **감춘다.** 연간·이번 달·이력 어디에도 나오지 않는다.
- 선택지
  1. 감춘다 (지금) — 화면이 짧고 할 일만 보인다
  2. '지난 건' 묶음에 흐리게 남긴다 — 그 해 전체 일정을 한 번에 볼 수 있다. 행동 문구·[입력] 은 숨긴다(AC-W31, W52)
- 추천: 2. 연간 화면은 "그 해 전체 일정표" 로 쓰이므로 22건이 다 보이는 편이 대조하기 쉽다.

## Q2. 당월 보드(`--board`) 창을 계속 둘지

- 근거: 웹 명세 기술 맥락 "웹과 역할 중복. 유지/폐기는 구현 시 판단"
- 지금 동작: **유지.** DB 를 쓰도록 바뀌었고 단계 이름·금액 규칙도 웹과 같은 코드를 쓴다.
- 선택지: 1. 유지 / 2. 폐기하고 `install-board.bat`·`start-board.bat` 제거 (웹 '이번 달' 로 대체)
- 추천: 2. 같은 정보를 보여 주는 창이 둘이면 고칠 곳도 둘이다. 다만 브라우저를 늘 열어 두기 싫다면 1.

## Q3. '이번 달' 집계 칸의 낱말

- 근거: 웹 명세 "이번 달 화면은 아직 `진행중 2건` 이라고 적는다… 맞추려면 지시가 필요하다"
- 지금 동작: 이번 달은 **진행중(끝나지 않은 건 전부) / 완료 / 기한 지남**. 연간은 진행중(`stage≥1`)·진행예정(`stage=0`)으로 나눈다.
- 선택지: 1. 지금대로 / 2. 이번 달도 진행중·진행예정으로 나눈다
- 추천: 2. 같은 낱말이 두 화면에서 다른 뜻이면 숫자를 믿기 어렵다.

## Q4. 웹 첫 화면

- 근거: 명세 AC-W60 은 "첫 화면은 이번 달". 2026-09-14 시안 검토에서는 '받은 알림' 이 맨 위였다.
- 지금 동작: **받은 알림** 이 첫 화면 (최근 시안을 따름).
- 선택지: 1. 받은 알림 / 2. 이번 달
- 추천: 1. 알림일이 지난 건만 모아 두는 화면이 매일 여는 목적에 더 가깝다.

## Q5. 공개 저장소의 실제 금액

- 근거: GitHub `Work-Automation` 은 공개 저장소다. 테스트 코드에 금융투자협회회비 금액(5,838,089)이 시험값으로 들어 있고 과거 커밋에도 남아 있다.
- 지금 동작: 새로 쓰는 테스트에는 가짜 금액을 쓴다. 기존 값은 그대로 두었다. **push 는 하지 않았다.**
- 선택지: 1. 그대로 / 2. 테스트 값을 가짜로 바꾸고 저장소를 비공개로 전환 / 3. 기록까지 지우기(강제 push)
- 추천: 2. 기록을 고쳐 쓰는 3 은 되돌릴 수 없어 사용자가 직접 판단해야 한다.

## Q6. 알림 팝업 오른쪽 여백

- 근거: 2026-09-15 시안 검토 때 물었으나 답이 없었다.
- 지금 동작: 작업 표시줄에는 틈 없이 붙이고 **오른쪽은 12px** 띄운다.
- 선택지: 1. 12px / 2. 0px (화면 끝까지)

## Q7. 백업 보관 기간

- 지금 동작: 하루 한 번(첫 실행 때) `자료폴더\backups\납부알림-YYYY-MM-DD.db` 를 만들고 **최근 30개**만 남긴다.
- 선택지: 보관 개수, 또는 백업 위치를 다른 드라이브(USB·사내 개인 드라이브)로
- 추천: 자료 폴더와 **다른 디스크**에 두는 것. PC 디스크가 망가지면 같은 디스크의 백업도 함께 잃는다. 경로는 `data-folder.txt` 처럼 `backup-folder.txt` 로 바꿀 수 있게 해 두었다.

## Q8. 스캔 문서(감독분담금 통보문·협회비 안내문) 판독

- 근거: README — 텍스트 추출 시 콤마·마침표가 사라져 신뢰 불가

- 선택지: OCR 도구 도입(설치 필요 → "추가 설치 0건" 제약과 충돌) / 지금대로
- 추천: 지금대로.

## Q10. 여러 항목을 한꺼번에 넣는 방법

- 근거: 엑셀 입력 경로를 없앴다 (ADR-0013, 명세 AC-W19).
- 지금 동작: 항목은 웹에서 한 건씩(분할납부는 월 쉼표로 한 번에) 넣는다.
- 선택지: 1. 지금대로 / 2. 웹에 "CSV 가져오기" 추가 (내려받은 CSV 를 고쳐 다시 올리는 방식)
- 추천: 1. 항목은 22건 수준이고 해마다 거의 바뀌지 않는다. 2 는 웹과 파일 두 편집 경로를 다시 만든다.

## Q11. GitHub 에 올리기

- 지금 동작: 이번 작업의 커밋은 **로컬에만** 있다 (`git log` 로 확인). 공개 저장소라 사용자가 Q5 를 정한 뒤 올리는 편이 안전하다.
- 올리려면: `git push origin main`

## Q9. `jbam-web` 폴더의 원래 git 기록

- 근거: 사용자가 만든 `jbam-web`(Next.js + shadcn 템플릿)에 별도 `.git` 이 있어 상위 저장소에 넣을 수 없었다.
- 지금 동작: 지우지 않고 `jbam-web/.git-template-backup` 으로 이름만 바꿔 두었다(저장소에는 올라가지 않음). 기록은 템플릿 첫 커밋 1개뿐이다.
- 선택지: 1. 백업 폴더 삭제 / 2. 그대로 보관

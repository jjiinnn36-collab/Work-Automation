# 신고·납부 자동화 — 공시 일정 조사와 설계안

- 날짜: 2026-09-17 (2판 — 일정을 기관 공시로 다시 확인, 수기 스캔본 대응 추가)
- 상태: **조사·설계 단계 (구현 전)** — 'E. 결정이 필요한 것' 을 정한 뒤 ADR 로 옮긴다
- 일정의 근거는 **각 기관 홈페이지·법령에 공시된 정보만** 쓴다. 회사 일정표는 근거로 쓰지 않는다.

## 요청

1. 신고기한이 되면 신고 사이트로 바로 이동
2. 신고하면 신고내역에서 해당 신고를 찾아 신고완료까지 자동 진행
3. 증빙자료와 납부금액을 자동으로 올림
4. 신고 과정의 불필요한 수작업을 없앰
5. **수기로 작성한 서류의 스캔본처럼 판독 신뢰도가 낮은 경우의 대책**

### 공시에서 새로 확인된 점

- **교육세 중간예납 금액** = 직전 과세기간 확정 산출세액 ÷ 직전 과세기간 월수 × 3 (12개월이면 ÷4). 2016년 시행령 개정으로 도입됐다 (보도 기준, 조문 원문은 미확인).
- **감독분담금**은 연 1회 고지액을 **4회 균등** 분할한다. 한꺼번에 낼 수 있고, **100만 원 이하면 3월 말일에 전액** 낸다 (제6조④⑤).
- **특별기여금**은 2003~2027년 25년간만 내는 부담금이다 → **2028년부터는 항목이 필요 없다.**
- **예금보험료·특별기여금**은 납부기한이 공휴일이거나 금융회사 휴무일이면 **다음 첫 영업일**이 기한이다. 연간 최소 납부액은 각각 10만 원이다.
- 산정자료는 예금보험공사 **보험료산정시스템**으로 낸다. 산정표·연평균 재무상태표 등은 **회사가 스스로 계산해 만든 전자 자료**다.
- 국세는 기한이 공휴일·주말이면 다음 날로 넘어간다. 공시 예: 2026년 부가세 확정 1.26, 교육세 1차 중간예납 6.1.

### 프로그램 등록값과 대조 (참고)

공시로 확인되는 항목(국세청·금융감독원·예금보험공사)은 현재 프로그램 항목과 월·기한이 모두 일치한다. 금융투자협회 회비(5~10월 20일)는 공시 근거가 없어 대조하지 못했다. 다음은 바꾸거나 정해야 한다.
- 특별기여금 건: 2027년 납부분 이후 종료 처리
- 감독분담금 금액: 고지액 한 번 입력 → 4회로 자동 분할 (C2)
- 교육세 중간예납 금액: 정기신고 산출세액에서 자동 계산 (C2)
- 금융투자협회 회비: 기한 근거가 공시에 없으므로 **고지 공문을 받은 문서로 첨부**해 근거로 삼는다

## C. 설계안

### C1. 기본 원칙 — "판독은 마지막 수단"

직전 제안은 결국 판독에 기대는 구조였다. 판독은 문서 상태에 따라 신뢰도가 크게 달라지므로 **금액을 얻는 순서**를 정한다.

| 순위 | 금액을 얻는 곳 | 신뢰도 | 사람 확인 |
|---|---|---|---|
| ① | **계산 규칙** — 이미 확정된 값에서 나오는 금액 (감독분담금 ÷4, 교육세 중간예납 = 확정세액 ÷4) | 매우 높음 | 원금액 한 번 |
| ② | **전자 원본** — 글자가 들어 있는 PDF (홈택스 접수증·신고서, 기관이 메일로 보낸 전자 고지서) | 높음 | 검산 통과 시 없음 (되돌리기만) |
| ③ | **회사 자체 계산 파일** — 예보료 산정표 같은 회사가 만든 엑셀 | 높음 | 파일·칸 위치를 한 번 지정 |
| ④ | **인쇄물 스캔** — 인쇄된 고지서를 스캔한 이미지 | 중간 | **판독값은 제안만**, 잘라 낸 원본 그림 옆에서 한 번 확인 |
| ⑤ | **수기 작성 서류 스캔** | 낮음 | **판독하지 않는다** → 아래 C3 |

### C2. 계산으로 입력을 없애는 부분

- **감독분담금**: 3월 고지서의 연간 분담금 한 번 입력 → 3·5·7·10월 4건에 균등 분할. 나눠떨어지지 않는 원 단위는 고지서 표기를 따르도록 **마지막 회차에서 맞추기**. 100만 원 이하이면 3월 1건만 남기고 나머지는 '해당 없음'.
- **교육세 중간예납**: 정기신고(3월)의 산출세액이 확정되면 그 해 1·2·3차 중간예납 금액을 자동으로 채운다. 원 단위 처리 규칙은 조문 확인 후 정한다.
- **금융투자협회 회비**: 연간 고지액과 분할 횟수를 한 번 입력 → 회차별 금액 (분할납부 기능 재사용, ADR-0010).
- 계산으로 나온 금액에는 `출처=계산(근거 건)` 을 남기고, 근거 금액을 고치면 따라서 다시 계산할지 묻는다.

### C3. 수기 작성 서류 — 읽지 말고, 처음부터 기록한다

수기 서류의 숫자는 **어딘가에서 계산해 손으로 옮겨 쓴 것**이다. 그 숫자를 스캔에서 다시 읽는 것은 '옮겨 쓰기 → 다시 읽기' 두 번의 오류 기회를 만든다. 그래서 흐름을 뒤집는다.

1. **입력이 먼저, 종이는 나중**: 프로그램에 금액·항목을 먼저 넣고, 그 값으로 서류 양식을 채워 **인쇄**한다. 서명·날인만 손으로 한다.
   → 스캔본은 **증빙 보관용**으로만 첨부하고 읽지 않는다.
2. 양식을 프로그램에서 인쇄할 수 없는 서류(기관 지정 양식)는 **두 번 입력 대조**:
   - 금액을 두 번 입력하게 하고 (두 번째는 첫 값을 가린 채) 같을 때만 저장한다.
   - 또는 **확인자 지정**: 입력한 사람과 다른 사람이 웹 화면에서 [확인]을 눌러야 '확정' 이 된다.
3. 스캔본에는 **확인 도장 정보**(확인자·확인일시·입력값)를 변경 기록으로 남겨, 나중에 스캔본과 입력값을 나란히 볼 수 있게 한다.
4. 손글씨 판독(필기 OCR)은 **하지 않는다**. 정확도가 높은 필기 인식은 대부분 외부 클라우드 서비스라 회사 서류를 밖으로 보내야 하고, PC 안의 Windows 기본 인식기는 필기에 약하다.

### C4. 인쇄물 스캔 — 판독은 '제안', 검산이 통과해야 채운다

- 판독 엔진: **Windows 기본 문자 인식(Windows.Media.Ocr)** — PC 안에서만 동작, 추가 설치 없음 (한국어 언어팩 필요 여부는 시험).
- 신뢰도를 높이는 장치:
  - **양식별 위치 지정**: 기관 고지서는 매년 같은 모양이므로 '금액 칸 위치' 를 한 번 지정해 두고 그 부분만 읽는다.
  - **숫자만 허용**, 쉼표 자리 검사 (세 자리마다), 앞뒤 공백·글자 제거.
  - **이중 표기 대조**: 고지서에 한글 금액(금 일백이십만원정)과 숫자가 함께 있으면 둘이 같아야 한다.
  - **합계 대조**: 세목 합 = 합계, 분할 합 = 고지액.
  - **범위 대조**: 전년 같은 건의 ±50% 밖이면 경고.
- 화면: 판독값 옆에 **잘라 낸 원본 그림**을 크게 보여 주고 [맞음]/[고치기]. 검산을 하나라도 통과하지 못하면 칸을 비워 두고 그림만 보여 준다.
- 스캔 품질 안내: 300dpi 이상·흑백·기울기 없음. 품질이 낮으면 판독을 시도하지 않고 "다시 스캔하거나 직접 입력" 으로 안내.

### C5. 자동 처리를 '믿어도 되는 만큼만' 켜기

- 판독 제안과 사람이 확정한 값을 **문서 종류별로 기록**하고 일치율을 설정 화면에 보여 준다.
- 한 문서 종류가 **연속 4회 정확히 일치**하기 전에는 그 종류는 항상 확인을 받는다. 한 번이라도 틀리면 다시 처음부터 센다.
- 전자 원본(②)도 같은 규칙을 따른다. 처음 몇 번은 확인을 받고, 믿을 만해지면 자동 + 되돌리기로 바뀐다.

### C6. 홈택스 건 흐름 (직전 안 유지, 판독 대상은 ②만)

| 단계 | 사람 | 프로그램 |
|---|---|---|
| 알림 | — | 기한 N영업일 전 카드, 준비물 목록, 주 버튼 **[홈택스에서 신고 ↗]** |
| 신고 | 홈택스에서 신고 | — |
| 결과 저장 | 접수증·신고서를 '홈택스 문서 폴더'에 PDF로 저장 | 폴더 감시 → 글자 추출 → 사업자번호·세목·과세기간으로 건 찾기 → 신고완료 + 금액 + 증빙 (C5 조건 충족 시 자동) |
| 전표 | ERP에 붙여 넣기 | **[전표 내용 복사]** |
| 납부 | 이체 승인 | 전자납부번호·금액 복사, [홈택스 납부 ↗] |
| 납부완료 | 국세전자납부확인서 PDF 저장 | 납부완료 + 증빙 |
| 세액 0·환급 | — | 납부 단계 '해당 없음' |

자동 기록 조건 (하나라도 어긋나면 "확인 필요" 카드): 문서 종류 인식 / 사업자번호 일치 / 가리키는 건이 정확히 하나 / 추적 시작일 이후·아직 그 단계 전 / 합계 검산 통과 / 기존 금액 없음 / 수정신고·기한후신고 아님. 같은 파일은 한 번만 반영(내용 해시), 원본 파일은 복사만 한다.

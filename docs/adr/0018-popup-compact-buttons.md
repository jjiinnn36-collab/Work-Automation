# ADR-0018 알림 팝업 버튼 — 작게, 두 번째 버튼은 옅은 채움 (B안)

- 상태: 채택
- 날짜: 2026-09-17
- 요청: "팝업 크기 대비 신고완료·오늘은 대기 버튼 비율이 크다, 오늘은 대기가 바탕과 구분되지 않아 버튼인지 모르겠다"
  → 제안(아티팩트 "기한 알림 버튼 다듬기": A 테두리 / B 옅은 채움 / C 반반 한 줄) → "B안으로 진행"

## 진단 (v6)

- 행동 버튼 34px = 창 높이 212 의 16%, 13px 굵은 글씨·완전한 알약 → 카드 내용보다 먼저 보인다.
- "오늘은 대기"·⋯ 는 바탕·테두리 없는 회색 글씨 — 안내 문구로 읽힌다.

## 근거

- NN/g: 단서가 약한(바탕·테두리 없는) 버튼이 있는 화면은 22% 더 오래 보고 시선 멈춤이 25% 많다.
- Fluent 2: 카드처럼 좁은 곳은 작은 크기, 주요 버튼은 한 화면에 하나.
- Material 3: 중요한 두 번째 행동에는 옅은 채움(tonal) 버튼.

## 결정

| 버튼 | 모양 |
|---|---|
| 다음 행동(전표 발행·신고완료…) | 주요 파랑, **28px**, 모서리 8, 12px 굵게 |
| 오늘은 대기 | **옅은 채움** `#f4f4f5` → 올림 `#e9e9eb` → 누름 `#e0e0e3`, 검정 글씨, 테두리 없음, 28px |
| ⋯ | 28×28 글자형(평소 바탕 없음, 올릴 때만 옅은 바탕), 모서리 8 |
| 되돌리기 · 웹에서 보기 | 옅은 채움 28px |
| 닫기(완료 장) | 주요 28px |
| ‹ › (넘기기 줄) | 글자형, 모서리 8 |
| 고른 뒤 표시 | 바탕 없는 흐린 글씨 `✓ 내일 다시 알림` / `✓ 처리함` / `✓ 모두 끝남` — 버튼과 헷갈리지 않게 |

- 모서리는 제안서 추천대로 둥근 사각형 8px(웹 화면 버튼과 같은 모양). 머리 아이콘(`!` ⚙ ▾)은 둥근 모양 그대로.
- 버튼 줄은 진행 막대 아래 14px(y=98). 창 크기 340×212 와 나머지 배치는 그대로.
- 부품: `PillButton.옅은채움`, `PillButton.반경`(음수 = 알약). 버튼 공통 규칙(ADR-0015 3-3)은 그대로 적용.
- 함께 고친 것: 카드 그리기가 처리 표시·되돌리기의 조건을 `Visible` 로 읽어 창을 띄우기 전에는 글자가 비던 문제
  (실제 창에서는 증상 없음) — 조건을 변수로 든다.

## 시험

- Smoke GUI-12: 행동 버튼 높이 28·모서리 8, '오늘은 대기' 옅은 채움, 고른 뒤 `✓ 내일 다시 알림`,
  옅은 채움 버튼 픽셀(안쪽 `#f4f4f5`, 모서리 바깥은 부모 그림, 테두리 없음).
- 실제 데모 팝업을 화면 캡처로 확인: 평소 / '오늘은 대기' 올림 / 대기 누른 직후 / 완료 장.

# ADR-0003 내 PC 전용 웹 서버

- 상태: 채택 (2026-09-15 구현, 소급 기록)
- 날짜: 2026-09-16

## 맥락

명세 AC-W1~W4: 관리자 권한 없이, localhost 에만, 설치 0건. 로그인 없음(사용자 지시).

## 결정

- `PaymentAlert.exe --web` 이 .NET `HttpListener` 로 `http://localhost:8317/` 을 연다. 사용 중이면 +1 씩 10개까지.
- 요청은 한 스레드에서 차례로 처리하고, 요청마다 DB 를 새로 연다(옛 자료를 붙들지 않음).
- 보안:
  - `Host` 머리글이 `localhost:포트` / `127.0.0.1:포트` 가 아니면 403 (DNS 재바인딩 차단).
  - 변경 요청(POST)은 `X-PaymentAlert: 1` 머리글 필수, `Origin` 이 있으면 같은 출처여야 함 (CSRF 차단).
  - JSON 문자열의 `< > &` 는 유니코드 이스케이프.
  - 증빙 파일은 DB 목록에 있는 것만, 증빙 폴더 안의 것만 내준다.
- 알림 영역 아이콘으로 상주, 이미 떠 있으면 브라우저만 연다(뮤텍스 + `%TEMP%\PaymentAlert.web-port`).
- 웹에서 항목을 고쳐 오늘 알릴 건이 되면 알림 팝업을 별도 프로세스로 띄운다 (2026-09-15 사용자 요청).

## 결과

- 웹서버가 죽어도 팝업은 DB 만 읽으므로 영향이 없다 (AC-W15).

# ADR-0020 웹 항목 추가 창 — 한 칸 흐름과 묶음 (A안)

- 상태: 채택
- 날짜: 2026-09-17
- 요청: "항목 추가 팝업창 입력칸이 창 안에 가득 차 있어 가독성이 떨어진다 — 리서치하고 제안"
  → 제안(아티팩트 "항목 추가 창 다시 짜기": A 한 칸 흐름 + 묶음 / B 단계형)
  → "A안으로, 선택 카드는 추천 이름으로, 금액규칙은 기존대로"

## 진단

672px 창에 두 칸으로 입력칸 11개와 설명 6줄. 무엇을·언제·어떻게·얼마가 섞여 있고,
가끔 쓰는 칸(홈페이지·비고)과 쓰지 않는 칸(변동일 때 고정금액)이 늘 보였다.

## 근거

- Baymard·NN/g: 여러 칸 양식은 빠뜨림·오해가 많고 한 칸 양식이 빠르다.
- NN/g: 이름표는 칸 바로 위, 성격이 다른 질문은 빈 공간과 제목으로 묶는다.
- Carbon: 설명은 필요한 곳에만 짧게.
- NN/g·Mirakl: 가끔 쓰는 것은 접어 두고 "선택" 이라고 밝힌다.

## 결정 (520px, 위→아래 한 줄기)

| 묶음 | 내용 |
|---|---|
| 항목 | 기관 · 비용명 (짧은 짝이라 한 줄) |
| 기한 | `매년 [월] [일]까지` / `[n] 영업일 전에 알림` 두 줄. 설명은 점 목록 두 줄(휴일 보정 / 분할납부 쉼표) |
| 진행 방식 | 선택 카드 4개 — **신고 후 납부 · 납부만 · 제출만 · 직접 정하기**(보이는 이름만 바뀜, 저장 값은 그대로). 카드 아래에 단계 요약. 직접 정하기를 고르면 그 아래 단계 편집기 |
| 금액 | **변동 / 고정**(기존 이름) 두 칸 토글. 고정일 때만 금액 칸. 금액 없는 흐름(제출만·금액 없음)이면 묶음을 숨김. 분할납부 회차 금액 표는 이 묶음 안 |
| 더 보기 (선택) | 홈페이지 이름·주소·비고. 이미 값이 있으면 펼친 채로 연다 |
| 요약 | 맨 아래 한 줄 — `회비 · 매년 5월 20일 · 납부만 · 고정 1,234,560원 · 3영업일 전 알림` |

- 묶음 제목은 짧은 명사(항목 · 기한 · 진행 방식 · 금액, 2026-09-18 사용자 요청). 12px 흐린 굵은 글씨 + 가는 선, 묶음 사이 24px, 본문만 스크롤하고 제목·버튼은 고정.
- 그대로: 제목 줄 끌어 옮기기, id 자동 생성, 단계 검사 규칙, 저장 요청 형식.
- 항목 관리 표의 흐름 칸은 저장 이름(신고납부 등)을 그대로 보인다 — 이번 요청은 선택 카드만.
- 화면 규칙: `FLOW_CARDS`, `flowLabel`, `dayLabel`, `itemSummary` (`lib/logic.ts`).

## 시험

- 화면 규칙 시험 10묶음: 카드 순서·이름, 기한일 표시, 요약(변동 / 고정 금액 / 고정인데 금액 없음 / 제출만 / 이름 없음·분할 월).
- 브라우저 패널(1280×1000)에서 확인: 창 폭 520px, 고정 → 금액 칸 나타남·요약 반영, 더 보기 펼침,
  직접 정하기 → 단계 편집기, 기한 두 줄.
- WebTests 256 통과(서버 요청 형식 변화 없음).

# ADR-0016 알림 팝업 시안 v5 — 집중 카드 (A안)

- 상태: 채택
- 날짜: 2026-09-16
- 대체: ADR-0009 의 카드 안 배치(크기·자리·넘기기·닫기 규칙은 그대로)
- 요청: "작은 화면에 데이터가 너무 많이 들어가서 사용자의 시선이 분산된다" → 리서치·제안(A 집중 카드 / B 목록 요약 / C 한 줄 토스트) → "A안으로 진행"
- 제안서: claude.ai 아티팩트 "기한 알림 팝업 다시 짜기" (실제 크기 시안·비교표·요소별 이동표)

## 진단 (v4)

- 340×260 에 요소 24개, 강조색 10곳(파랑 5 · 빨강 4 · 주황 1), 글줄 8줄, 글씨 크기 6가지.
- 같은 정보가 여러 번: 건수 3번(4건 · 남은 4건 · 점 4개), 기한 4번(상태 글 · 날짜 · 빨간 띠 · 빨간 점),
  다음 할 일 2번(파란 단계 라벨 · 버튼).
- 결정에 안 쓰는 정보가 같은 무게: 기관, 오늘 날짜, 단계 라벨 3개, 밀린 건수, 꺼진 닫기 버튼.

## 근거

- Windows 알림 지침: 본문 두 줄, 알림은 시간을 아끼고 산만하게 하지 않는다.
- Apple HIG: 간결하게, 동작은 몇 개로, 여러 알림은 묶어서.
- 힉의 법칙·시각 위계: 주요 행동 하나만 강조.
- 점진적 공개(NN/g): 드물게 쓰는 것은 한 층 아래로.

## 결정 (340×212)

| 영역 | v5 |
|---|---|
| 머리 (44px) | `기한 알림` 흐린 굵은 글씨 + 위치 `1/4` (접으면 파란 `4건`) · 오른쪽 `!` `⚙` `▾` |
| `!` | 자료 확인(공휴일 등)과 오래 밀린 건을 한 버튼으로. 둘 다 없으면 숨김. 누르면 두 내용을 한 창에 |
| 1줄 | 비용명 19px 굵게 |
| 2줄 | 상태 글 + `· 5/20 (수) · 금액`. **빨강은 기한 지나고 아직 안 고른 건의 상태 글 하나뿐**. D-n·오늘 기한은 검정, 고른 건은 흐림 |
| 진행 | 단계마다 한 칸인 가는 막대 + `1/3` (`StepBar`). 단계 이름은 풍선(✓ 끝낸 곳, ▶ 다음 할 곳) |
| 행동 | 파란 `[다음 행동]` 하나(화면의 유일한 파랑) · 글자형 `오늘은 대기` · 오른쪽 글자형 `⋯` |
| 고른 뒤 | 옅은 칩 `내일 다시 알림` / `처리함` / `모두 끝남` · 글자형 `되돌리기` |
| 넘기기 | 점만. 지금 = 긴 짙은 회색, 안 고름 = 빈 고리, 고름 = 옅은 회색, 지나고 안 고름 = 빨강. ‹ › 화살표 없음(끌기·방향키·점 누르기) |
| 다 고른 뒤 | 400ms 뒤 완료 장: "오늘 확인할 건을 모두 골랐습니다" · "진행 N건 · 오늘은 대기 M건" · `[닫기]` `웹에서 보기`. 점을 누르면 카드로 돌아간다 |
| 빠진 것 | 오늘 날짜(작업 표시줄 시계), 기관(⋯ 메뉴 맨 위 + 풍선), 바닥 줄(안내·꺼진 닫기), 빨간 카드 띠 |

- 결정 질문 2(기관 이름)·3(금액 미입력 표시)은 제안서의 추천대로:
  기관은 첫 화면에서 빼고 ⋯ 메뉴·풍선으로, 금액이 없으면 파랑 대신 흐린 `금액 미확인` (웹과 같은 낱말 유지).
- 닫기 규칙(ADR-0009)은 그대로: 모두 고르기 전에는 닫히지 않고 Alt+F4·Esc 도 막는다.
- 접기·등장 애니메이션(ADR-0015 3-5·3-6), 버튼 공통 규칙(3-3)은 그대로 쓴다.
- 새 부품: `StepBar`(진행 막대), `PillButton.글자형`(테두리·바탕 없는 두 번째 선택지·아이콘, 올리거나 누를 때만 옅은 바탕).

## 시험

- Smoke GUI-9: 상태 글 'N영업일 지남'·빨강, 기한 전 'D-n' 검정, 부가 줄 `· 9/11…`, 막대 `1/전체`,
  머리 위치 `1/3`→`2/3`, 접으면 `3건`, `!` 유무·요약, 완료 장(넘김 시각·설명·전체 건수·점 유지·'지금' 점 없음),
  점 누르면 카드로, 남은 건이 생기면 완료 장 대신 그 건으로.
- GUI-2 크기 340×212, GUI-4 설정 버튼 글자가 비어 있지 않음(구현 중 톱니 글자가 빈 문자열이 된 실수를 막음).

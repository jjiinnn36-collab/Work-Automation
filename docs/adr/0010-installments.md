# ADR-0010 분할납부: 회차는 독립 항목, 묶음으로 한 창에

- 상태: 채택
- 날짜: 2026-09-16
- 관련: AC-W32 ~ AC-W42, `docs/decisions-needed.md` 없음 (명세에서 확정)

## 맥락

금융투자협회 회비(6분납), 감독분담금(4분납)은 회차별 금액이 **안내문 한 장**에 적혀 온다.
기존 자료는 이미 `kofia-05 … kofia-10` 처럼 회차마다 독립 id 를 가진다.
회차마다 따로 입력하게 하면 한 문서를 여러 번 열어야 하고 합계를 대조할 수 없다.

## 결정

- 회차는 계속 **독립 항목**이다. 진행 단계·증빙·알림은 회차별로 따로 돈다 (기존 구조 유지).
- 항목에 `묶음` 칸을 둔다. 같은 묶음의 회차를 한 창에서 다룬다.
  - 옛 자료는 스키마 2판 이관이 id 모양(`접두-두자리`)과 기관·비용명으로 묶음을 찾아 준다 (ADR-0006).
- 항목 추가에서 `월` 에 쉼표(`5,6,7`)가 있으면 `{id}-05`, `{id}-06` … 을 **한 트랜잭션**으로 만들고 묶음 = `{id}`.
  - 회차 수는 `월` 칸만 정한다. 금액 표로 행을 늘리거나 줄이지 않는다 (AC-W42).
  - 같은 월 중복·범위 밖 월은 400, 이미 있는 회차 id 는 409. 고칠 때(edit) 쉼표는 400 — 회차는 하나씩 고친다.
  - 폼에서 회차 금액(`amt_MM`)·연도·출처를 함께 보낼 수 있다. **연도별 금액**으로 저장한다 — 마스터 고정금액이 아니다 (AC-W41).
  - 비운 회차는 미확인으로 남는다 (AC-W40). **균등 분배로 채우지 않는다** (AC-W37).
- `GET /api/group?y=&group=` — 모든 회차와 합계·입력 건수 (AC-W33, W35).
- `POST /api/group/amounts` — 회차 금액을 한 번에, 출처는 한 번만 (AC-W34). 빈 칸은 건드리지 않고 넣은 게 없으면 400 (AC-W89).
- 추적 시작일 이전 회차는 `beforeStart` 로 알려 화면이 입력칸을 숨긴다 (AC-W31).

## 결과

- 문서 판독의 "회차 합 = 문서 총액" 규칙(AC-W36)은 부가세(단일 건)만 자동 판독하므로 지금은 해당 건이 없다.
  스캔 안내문 판독은 `decisions-needed.md` Q8.

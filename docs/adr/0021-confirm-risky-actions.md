# ADR-0021 되돌리기 어려운 동작 확인 — 설정 탭, 전체 점검 목록

- 상태: 채택(설정 탭) / 제안(나머지 후보)
- 날짜: 2026-09-17
- 요청: "설정 탭에서 인증키 삭제 버튼을 누르니 바로 삭제된다, 한 번 더 확인하는 장치가 필요하다"
  + "해당 탭이 아니더라도 전체적으로 이런 위험을 대비할 지점을 리스트업"

## 결정 (구현)

설정 탭의 세 동작은 확인 창을 거친 뒤에만 실행한다. 문구는 `settingsConfirm`(`lib/logic.ts`) 한 곳.

| 동작 | 확인 창 | 강조 |
|---|---|---|
| 인증키 지우기 | "공휴일 인증키를 지울까요?" — 새 해 공휴일을 못 받음, 받은 자료는 남음 | 위험(빨강) |
| 인증키 저장 (이미 키가 있을 때) | "인증키를 새 키로 바꿀까요?" — 활용신청한 키인지 확인 | 보통 |
| 추적 시작일 제한 없애기 | "추적 시작일 제한을 없앨까요?" — `2026-09-01 이전` 건이 기한 지남으로 한꺼번에 뜰 수 있음 | 위험(빨강) |

- 서버 확인: 인증키 지우기는 키 파일만 지운다(공휴일 자료는 DB 에 남음).
- 함께 고친 문구: 항목 관리의 삭제 확인에서 "같은 id 로 다시 만들면 이어진다" 를 뺐다(id 자동 생성, ADR-0015).
- 시험: 화면 규칙 11묶음(세 문구의 강조·동작 이름·시작일 표시). 실제 설정 화면에서 '제한 없애기' → 확인 창 → 취소 → 시작일 그대로.

## 전체 점검 (2026-09-17)

### 이미 막혀 있는 것
- 웹: 항목 삭제·금액 지우기·첨부 삭제·한 단계 되돌리기는 확인 창.
- 팝업: 단계 되돌리기는 확인, 모두 고르기 전에는 닫히지 않음(✕ 없음, Alt+F4·Esc 막힘).
- 자료: 항목을 지워도 진행 기록·금액·증빙은 남음, 매일 DB 사본, 두 창이 동시에 바꾸면 늦은 쪽 거절.

### 남은 후보 (우선순위 순) — 1~6 은 ADR-0022 에서 구현, 7~11 미구현

| # | 어디 | 위험 | 제안 |
|---|---|---|---|
| 1 | 웹 항목·금액·회차 금액 창 | 입력 중에 ✕·Esc·바깥을 누르면 입력값이 바로 사라짐 | 바뀐 내용이 있으면 "저장하지 않고 닫을까요?" |
| 2 | 팝업 행동 버튼 | 누른 뒤 0.4초 뒤 다음 카드의 같은 자리에 같은 파란 버튼이 옴 → 연달아 누르면 다음 건까지 처리 | 넘긴 직후·밀기 중 0.3초 입력 무시 |
| 3 | 웹 진행 버튼 | 누르면 바로 저장, 되돌리기는 ⋯ 메뉴 안 | 저장 알림에 "되돌리기" 버튼 |
| 4 | 웹 '오늘은 대기' | 취소 방법 없음(팝업에만 있음) | 웹에도 대기 취소 |
| 5 | 웹 금액 입력 | 이미 넣은 금액을 다른 값으로 덮어써도 경고 없음 | 창에 "지금 금액 → 새 금액" 표시, 다르면 확인 |
| 6 | 웹 회차 금액 한 번에 | 이미 들어간 회차 금액을 한꺼번에 덮어씀 | 바뀌는 회차 표시 후 확인 |
| 7 | 웹 항목 수정 | 진행 중인 건의 진행흐름·단계 수를 바꾸면 단계가 잘리거나 뜻이 바뀜 | 진행 중인 건이 있으면 경고 |
| 8 | 웹 추적 시작일 저장 | 날짜를 옮기면 건이 사라지거나 기한 지남이 한꺼번에 생김 | 영향 받는 건수를 보여 주고 확인 |
| 9 | 알림 영역 아이콘 '끄기' | 웹 서버가 바로 꺼짐 | 확인 창(낮음) |
| 10 | 웹 공휴일 받기 | 받아 오다 실패할 때 기존 자료가 남는지 화면에서 알 수 없음 | 실패 시 기존 자료 유지 여부 점검·안내 |
| 11 | 웹 문서 열기 | 첨부 파일을 기본 프로그램으로 바로 실행(엑셀 매크로 등) | 실행 가능한 형식은 한 번 확인 |

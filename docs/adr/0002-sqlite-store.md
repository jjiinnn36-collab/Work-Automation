# ADR-0002 자료 저장소를 SQLite 파일 하나로

- 상태: 채택 (2026-09-15 구현, 소급 기록)
- 날짜: 2026-09-16

## 맥락

웹 명세(2026-09-13)는 "DB 도입 없음, TSV 유지"였다. 이후 사용자가 웹과 실행 프로그램을 연동하고
"웹사이트 자료의 저장 방식만 정하라"고 했고(2026-09-15), 자료는 사내 서버가 아니라 **내 PC 안의 별도 폴더**에
두기로 했다. TSV 는 팝업·보드·웹 세 프로세스가 동시에 쓸 때 파일 단위 교체라 병합 규칙을 코드로 지켜야 했다.

## 결정

- Windows 에 내장된 `winsqlite3.dll` 을 P/Invoke 로 부른다. DLL 배포·설치 0건 제약을 지킨다.
- 파일 하나 `납부알림.db`, WAL 모드, `busy_timeout 5000`, 쓰기는 `BEGIN IMMEDIATE` 트랜잭션.
- 금액은 원 단위 오차를 막으려 TEXT(불변 문화권 decimal)로 저장한다.
- 자료 폴더는 `data-folder.txt` 로 바꿀 수 있고 기본은 `data\`.
- DB 가 없고 옛 TSV 가 있으면 최초 실행 때 한 번 옮긴다 (`Importer.최초이전`). 원본 TSV 는 건드리지 않는다.

## 결과

- 좋은 점: 동시 쓰기 안전, 부분 갱신, 백업(`VACUUM INTO`) 가능.
- 치르는 값: 사람이 메모장으로 고칠 수 없다 → 편집은 웹 화면으로만 한다 (명세 AC-W7 방향과 일치).
- 명세 AC-W12("같은 tsv 를 읽고 쓴다")는 이 ADR 로 대체된다.

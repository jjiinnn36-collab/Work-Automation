# ADR-0019 팝업 — '오늘은 대기' 취소, 다 고른 뒤 닫기로 가는 길, 안내 문구 정리

- 상태: 채택
- 날짜: 2026-09-17
- 요청(사용자 제보):
  1. 팝업에서 "한 단계 되돌리기" 가 실행되지 않는다.
  2. 모두 고른 뒤 카드를 다시 확인하고 나니 팝업을 닫을 버튼이 사라졌다.
  3. `!` 알림 맨 아래 "매일 묻지는 않지만 끝내야 조용해집니다 …" 는 필요 없다.
  4. 웹 연간 탭 제목 아래 "추적 시작일 … 이전 … 흐리게" 설명은 필요 없다.
  5. 항목 관리 탭 안내가 한 줄로 이어져 읽기 어렵다.

## 원인

1. 되돌리기는 **단계만** 한 칸 내렸다. 데모의 건은 모두 첫 단계라 메뉴가 꺼져 있었고,
   더 근본적으로 '오늘은 대기' 를 누른 것을 취소하는 길이 어디에도 없었다(단계 0 이면 아무것도 안 함).
2. 완료 장은 "마지막으로 고른 직후" 자동 넘김으로만 나왔다. ‹ 로 카드를 다시 보면 돌아갈 길이 없었다
   (끝에서 › 는 꺼짐, ADR-0017 의 "끝에서 멈춤").

## 결정

### 되돌리기 = 가장 최근에 한 일
- 오늘 '오늘은 대기' 를 눌렀으면 **대기 취소**: 단계는 그대로, 오늘 확인 표시만 지워 다시 묻는다. 묻지 않고 바로.
- 아니고 단계가 있으면 **한 단계 되돌리기**(지금처럼 한 번 묻는다).
- 둘 다 아니면 되돌릴 것 없음(메뉴 꺼짐).
- ⋯ 메뉴 문구가 할 일을 말한다: `'오늘은 대기' 취소` / `한 단계 되돌리기 (전표발행 → 고지서수령)`.
- 고른 뒤 카드의 옅은 채움 `되돌리기` 버튼도 대기한 건에 보인다.
- DB: `Store.대기취소(연도, id, 기대단계, 지금, 오늘, 출처)` — 한 트랜잭션, 화면이 본 단계와 다르거나
  오늘 대기한 건이 아니면 `StageConflictException`, 변경 기록 `대기취소`.
- 웹 화면에는 아직 대기 취소가 없다(요청 범위 밖, 필요하면 같은 저장소 동작으로 붙이면 된다).

### 다 고른 뒤에는 마지막 카드에서 닫기로
- 남은 건이 없으면 마지막 카드의 › 와 바닥 줄이 켜지고, 줄은 `모두 골랐습니다 · 닫으러 가기`.
  누르면 완료 장(닫기)으로 밀려 간다. 남은 건이 있으면 지금처럼 끝에서 멈춘다.
- 건이 하나뿐이어도 다 고른 뒤·완료 장에서는 넘기기 줄을 보인다(점은 숨김).

### 문구
- `!` 의 밀린 건 안내에서 마지막 설명 문단을 뺐다.
- 웹 연간 탭 설명은 `전체 N건` 만.
- 웹 항목 관리 안내는 제목 + 세 줄 목록(정하는 것 / 금액 넣는 곳 / 분할납부 넣는 법).

## 시험

- DbTests DB-21: 대기 안 한 건 거절, 어제 대기는 오늘 취소 대상 아님, 취소 뒤 확인 표시 없음·단계 유지·DB 반영,
  기록 `대기 → 대기취소`, 화면이 본 단계와 다르면 거절.
- Smoke GUI-13: 대기한 건은 `대기취소`, 취소 뒤 다시 고를 수 있음, 진행한 건은 `되돌리기`;
  다 고른 뒤 앞 카드 › 는 다음 카드, 마지막 카드 › 켜짐·`모두 골랐습니다 · 닫으러 가기`·› 로 완료 장.
- 실제 데모 팝업: 대기 → ‹ → 되돌리기 버튼 보임 → 누르면 다시 '오늘은 대기' 보임 /
  모두 대기 → 완료 장 → ‹ 로 카드(닫기 숨김) → 마지막 카드 › → 완료 장(닫기 보임).

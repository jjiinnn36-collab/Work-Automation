# ADR-0017 알림 팝업 건 넘기기 — 다음 건 미리보기 줄과 밀기 움직임

- 상태: 채택
- 날짜: 2026-09-16
- 요청: "알림 리스트를 내비게이션하는 게 불편하다" → 리서치·제안(아티팩트 "기한 알림 건 넘기기")
  → "다음 건 미리보기와 애니메이션만 적용, 미리보기 줄 양 끝에 넘기기 버튼(머리의 넘기기 묶음 없이)"
  → 중간 지적: "점이나 끌기로 넘길 때도 움직임이 있어야 한다, 끌기는 알아차리기 어렵다"

## 진단 (v5)

| 방법 | 문제 |
|---|---|
| 아래 점 | 7×7px — WCAG 2.2 최소 24px 의 1/3, 이름이 없어 눌러 봐야 앎 |
| 본문 끌기 | 표시 없음, 손을 따라오지 않음 → 기능이 있는지 모름 |
| ← → | 팝업에 초점이 있어야 함 |
| 자동 넘김 | 뒤에 남은 건이 없으면 한 바퀴 돌아 앞 건으로 — 알리지 않음 |
| 모든 넘기기 | 내용이 순간적으로 바뀌어 방향·거리가 안 보임 |

근거: NN/g·Baymard(점은 잘 안 보이고 누르기 어려움, 이름·요약으로 대체 권장),
Smashing Magazine(이전·다음은 한 묶음), WCAG 2.2 SC 2.5.8(24×24px).

## 결정

### 바닥 넘기기 줄 (32px, 점 줄 대체)

`‹  다음 교육세 예정 · D-2   ●○○○  ›`

- `‹` `›` — 32×26 글자형 버튼. 처음에서 ‹, 끝에서 › 는 꺼진다. **한 바퀴 돌지 않는다.**
- 가운데 줄 전체가 “다음 건으로” 버튼. 다음 건의 이름(굵게)과 짧은 상태
  (`D-2` · `오늘 기한` · `5일 지남` · `내일 다시` · `처리함` · `모두 끝남`)를 미리 보여 준다.
  마지막 건이면 `마지막 건입니다`(꺼짐).
- 점은 위치 표시만 한다(`PageDots.누를수있음 = false`). 누를 곳은 ‹ › 와 줄.
- 완료 장에서는 `N건 모두 골랐습니다`, ‹ 는 마지막으로 보던 카드로 돌아가고 › 는 꺼진다.
- 머리의 `1/4` 위치 글자는 그대로 두고, 머리에 넘기기 버튼은 두지 않는다(사용자 결정).
- 마우스 휠 넘기기는 넣지 않았다(요청 범위 밖).
- 건이 한 개면 줄 전체를 숨긴다.

### 밀기 움직임 (`SlideOverlay`)

- 모든 넘기기(‹ › · 줄 · 방향키 · 자동 넘김 · 완료 장 오가기)가 같은 움직임:
  뒤쪽 건이면 지금 카드가 왼쪽으로 밀려나고 새 카드가 오른쪽에서, 앞쪽 건이면 반대로.
  자동 넘김이 앞쪽 남은 건으로 갈 때도 오른쪽으로 밀어 “되돌아감” 을 보인다.
- 220ms, ease-out cubic(`AlertForm.부드럽게`). 여러 칸 건너뛰어도 한 번만 민다.
- 카드 모습을 그림으로 떠서(`DrawToBitmap`) 본문 자리만 덮어 그린다 —
  WinForms 컨트롤을 직접 옮기면 깜빡이고 느리다. 머리·넘기기 줄은 덮지 않는다.
- 실측(실제 창, 계측 로그): 틱 약 16ms 간격, 220ms 에 정확히 끝(-31 → -144 → -268 → -322 → -340px).

### 끌기 — 손을 따라오게

- 6px 넘게 움직이면 이전·지금·다음 카드 모습을 떠서 덮개가 포인터를 그대로 따라온다.
- 넘어갈 카드가 없는 쪽(처음·끝)은 1/3 만 따라오며 버틴다.
- 80px 이상 끌거나 0.5px/ms 보다 빠르게 튕기면 넘어가고, 아니면 제자리로 돌아온다.
  남은 거리에 비례해 짧게 마무리(최소 90ms).
- 카드 위 커서는 좌우 화살표 모양 — 옆으로 끌 수 있음을 알린다. 주된 수단은 여전히 ‹ ›.
- 완료 장·접힌 상태·건 1개·화면 효과 꺼짐에서는 끌기 움직임을 쓰지 않는다
  (효과가 꺼져 있으면 예전처럼 놓는 순간 40px 기준으로 넘김).

### 공통

- Windows 화면 효과가 꺼져 있거나 창이 보이지 않으면 움직임 없이 바로 바꾼다.
- 움직이는 중에 다시 넘기면 지금 움직임을 끝내고 새로 시작한다.

## 시험

- Smoke GUI-10: 마지막 건 안내·‹ › 켜짐/꺼짐, 끝에서 멈춤(돌지 않음), 미리보기 문구(이름·처리함·내일 다시),
  점은 위치 표시만, 완료 장 줄 문구·‹ 로 보던 카드 복귀.
- Smoke GUI-11: 전환 방향(다음=왼쪽, 이전=오른쪽)·끝 알림 한 번, 끌기 따라옴·버티기(1/3)·짧게 끌면 복귀·
  80px 넘으면 다음·빠른 튕김이면 이전·카드 없는 쪽은 멀리 끌어도 복귀.
- 로컬 위키 "애니메이션 추가 후보" 의 2번(카드 슬라이드)은 이 결정으로 구현, 4번(페이지 점 이동)은
  점이 위치 표시로 바뀌어 필요성이 줄었다.

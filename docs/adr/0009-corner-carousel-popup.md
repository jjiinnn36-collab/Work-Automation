# ADR-0009 알림 팝업을 오른쪽 아래 코너형·한 장씩 넘기기로

- 상태: 채택
- 날짜: 2026-09-16
- 관련: 시안 `코너 알림 팝업` v4 (claude.ai artifact, 2026-09-15 사용자 검토), AC-11, AC-25

## 맥락

기존 팝업은 화면 가운데 680×424 창에 모든 건을 세로로 나열했다. 사용자는 시안 검토에서 다음을 정했다.

- 화면 **오른쪽 아래, 작업 표시줄 바로 위**에 붙인다 (틈 없음). 제목줄을 없애고 **둥근 모서리**.
- 크기 **340×260** (가로 ½, 세로 약 ⅔), 바닥 닫기 줄 높이 ¼ 줄임.
- 여러 건은 **한 장씩 옆으로 넘기고**, 아래 **점**이 순서와 상태를 보여 준다.
- 기한 지난 건은 **꽉 찬 빨간 점**.
- **자리 고정**(끌어 옮기지 않음), **고르면 다음 건으로 자동 넘김**.

## 결정

- `AlertForm` 을 다시 썼다. 공개 계약(생성자 인자, `RefreshState`, `단계변경` 통로, 닫기 규칙)은 그대로.
- 자리: `Screen.PrimaryScreen.WorkingArea` 기준 `Right-340-12, Bottom-260`. 작업 표시줄이 위·옆에 있어도 작업 영역 기준이라 가려지지 않는다.
  오른쪽 12px 는 `decisions-needed.md` Q6 에서 사용자 확인을 기다린다.
- 모양: `FormBorderStyle.None` + Windows 11 은 `DwmSetWindowAttribute(DWMWA_WINDOW_CORNER_PREFERENCE=ROUND)`,
  그보다 옛 Windows 는 `CreateRoundRectRgn` 으로 창을 깎는다. `CS_DROPSHADOW` 로 그림자.
- 구성 (위→아래): 머리 44px(‘기한 알림 N건’, 날짜, 자료 경고가 있으면 ‘⚠ 자료 확인’) → 카드 316×150 → 넘기기 줄(‹ 점 ›) → 바닥 38px(남은 건수·밀린 건·닫기).
- 카드: 상태(D-n영업일/오늘이 기한/기한 n영업일 지남)·기관 / 비용명·실납부일·금액 / 지점 도형 / 버튼.
  아직 안 고른 건 = `[행동]`(ADR-0005 의 행동 문구) `[오늘은 대기]` `[⋯]`,
  고른 건 = `처리함`/`내일 다시 알림` 표시 + `[되돌리기]` `[⋯]`.
  `⋯` 메뉴: 증빙 첨부, 증빙 폴더 열기, 되돌리기, 홈페이지 열기, 웹 화면에서 보기(웹 서버가 떠 있을 때).
- 넘기기: ‹ › 버튼, 점 누르기, 키보드 ← →, 카드를 40px 이상 끌기. 첫 장은 아직 안 고른 건 중 기한이 가장 이른 건.
- 자동 넘김: 진행·대기가 성공하면 0.4초 뒤 **다음 남은 건**(한 바퀴 돌며 찾음)으로.
- 점: 지금 보는 건 = 길쭉한 파랑(기한 지남이면 빨강), 남은 건 = 빈 점, 기한 지난 건 = 꽉 찬 빨강, 고른 건 = 꽉 찬 회색.
  1건이면 점 줄을 숨기고, 13건 이상이면 `3 / 15` 글자로.
- 유예(5영업일)를 넘긴 밀린 건은 바닥의 빨간 `밀린 N건` 을 누르면 목록이 뜬다.
- 색·글꼴은 웹 화면(shadcn neutral, ADR-0007)과 같은 값으로 `UiKit` 토큰을 바꿨다.

## 결과

- 한 번에 한 건이라 스크롤이 없다. 대신 여러 건의 전체 모습은 점으로만 본다 — 목록 보기는 웹 '받은 알림'.
- 창을 옮길 수 없다. 다른 창을 가리면 처리하거나 대기를 눌러야 한다 (차단형 알림의 의도).

## 검증

`FormSmokeTest` [GUI-2]: 자리·크기, 제목줄 없음, 넘기기 경계, 행동 문구, 점 상태, 다음 남은 건 찾기, 닫기 활성, 1건·15건 표시.

# 정기 납부 기한 알림

정기적으로 납부·신고해야 하는 항목의 기한을 매일 감시하고, 기한 며칠 전에 **화면 오른쪽 아래 팝업**으로 알린다.
팝업은 표시된 모든 건을 처리하거나 '오늘은 대기' 를 골라야 닫히며, 처리 전까지 매일 다시 뜬다.
일정 조회·항목 편집·금액·증빙·이력은 **내 PC 전용 웹 화면**에서 한다.

목표는 **기한 누락 0건**이다. 실제 이체·송금은 하지 않는다.

| 구성 | 실행 | 하는 일 |
|---|---|---|
| 알림 팝업 | `PaymentAlert.exe` (매일 9시 자동) | 알림일이 지난 건을 한 장씩 보여 주고 진행·대기를 받는다 |
| 웹 화면 | `PaymentAlert.exe --web` (로그온 시 자동) | `http://localhost:8317/` — 받은 알림·이번 달·연간·이력·항목 관리·설정 |
| 당월 보드 (선택) | `PaymentAlert.exe --board` | 이번 달 기한을 늘 띄워 두는 작은 창 |

세 가지 모두 같은 자료 파일(`data\납부알림.db`)을 읽고 쓴다. 웹 화면이 꺼져 있어도 팝업은 그대로 동작한다.
설치할 것은 없다 — Windows 에 들어 있는 .NET Framework 와 SQLite 만 쓴다.

## 설치

### 1. 환경 확인 (최초 1회)

`check-env.bat` 을 실행한다. 관리자 권한은 필요 없고 시스템을 바꾸지 않는다.
바탕화면에 `env-check-result.txt` 가 만들어진다.

| 항목 | 정상 | 문제일 때 |
|------|------|-----------|
| `[6] DOCS_EXEC_OK` | exe 생성·실행 가능 | AppLocker 등으로 차단됨 |
| `[7] WINFORMS_OK` | 팝업 가능 | GUI 사용 불가 |
| `[11] SCHTASKS_CREATE=OK` | 매일 자동 실행 등록 가능 | `[12]` 시작프로그램으로 대체 |
| `[13] HTTPS=REACHABLE` | 공휴일 자동 갱신 가능 | 공휴일은 함께 배포한 자료로만 |
| `[15] LISTEN=OK CONNECT=OK` | 웹 화면 사용 가능 | 보안 프로그램이 localhost 를 막음 |

### 2. 빌드

`build.bat` → `PaymentAlert.exe` 가 만들어진다. 웹 화면 파일(`web\`)은 저장소에 이미 들어 있어 따로 만들 필요가 없다.

### 3. 웹 화면 켜기

- `start-web.bat` — 지금 켠다. 알림 영역(시계 옆)에 아이콘이 생기고 브라우저가 열린다.
  아이콘을 두 번 누르면 다시 열리고, 오른쪽 클릭 → 끄기.
- `install-web.bat` — 로그온할 때마다 자동으로 켠다 (브라우저는 열지 않음).

### 4. 처음 쓰기 — 항목 넣기

1. 웹 화면 **설정** 에서 **추적 시작일**을 정한다 (예: 쓰기 시작한 달의 1일).
   이보다 이른 기한은 다루지 않는다. 안 정하면 과거 건이 모두 '기한 지남' 으로 잡힌다.
2. **항목 관리 → 항목 추가** 에서 기관·비용명·진행흐름·월·기한일·알림 영업일·금액규칙을 넣는다.
   - 분할납부는 월에 `5,6,7,8,9,10` 처럼 쉼표로 넣으면 회차마다 항목이 생기고, 회차 금액 표가 함께 나온다.
   - 신고 홈페이지 주소를 넣으면 화면에 바로가기가 생긴다. 없으면 그 자리에 '문서 열기'.

예전 판(TSV 파일)을 쓰던 PC 는 새 판을 처음 켤 때 `data\*.tsv` 가 자동으로 옮겨진다. 원본 TSV 는 지우지 않는다.

### 5. 매일 자동 알림 등록

`install-task.bat` — 매일 오전 9시에 팝업을 확인한다. PC 가 꺼져 있던 날은 켠 뒤 곧바로.
해제: `schtasks /delete /tn "납부기한알림" /f`

## 매일 쓰기

### 알림 팝업

- 화면 오른쪽 아래, 작업 표시줄 바로 위에 뜬다. 자리를 옮길 수 없고 늘 맨 위에 있다.
- 한 번에 한 건. 아래 점이 몇 번째 건인지 알려 준다.
  길쭉한 파란 점 = 지금 보는 건, 빈 점 = 아직 안 고른 건, **빨간 점 = 기한 지난 건**, 회색 점 = 고른 건.
- 넘기기: ‹ › 버튼, 점 누르기, 키보드 ← →, 카드를 옆으로 끌기.
- 건마다 둘 중 하나를 고른다. 고르면 잠시 뒤 다음 남은 건으로 넘어간다.
  - **[행동]** (전표 발행 / 납부완료 / 신고완료 / 제출하기) — 한 단계 진행
  - **[오늘은 대기]** — 오늘은 할 게 없다. 내일 다시 뜬다
- 모든 건을 고르면 **닫기** 가 켜진다. X·Alt+F4·Esc 로는 닫히지 않는다.
- `⋯` : 증빙 첨부·폴더 열기, 되돌리기, 홈페이지 열기, 웹 화면에서 보기.
- 누르는 즉시 저장된다. 그사이 웹 화면에서 같은 건을 먼저 바꿨으면 알려 주고 최신 상태로 맞춘다.
- 기한이 지나고 **5영업일** 이 넘은 건은 매일 묻지 않고 바닥의 빨간 **밀린 N건** 으로만 알린다.

### 진행흐름

| 진행흐름 | 지점 (끝낸 것) | 누르는 행동 |
|---|---|---|
| `신고납부` | 신고서 작성 → 신고 → 전표발행 → 납부 | 신고완료 → 전표 발행 → 납부완료 |
| `납부만` | 고지서수령 → 전표발행 → 납부 | 전표 발행 → 납부완료 |
| `제출만` | 제출자료 작성 → 제출 | 제출하기 |

도형: 끝낸 지점은 회색, **지금 할 지점은 파랑**, 남은 지점은 빈 원.
`전표발행` 은 ERP 에 상신하지 않는다. 했는지 표시만 한다.

**잘못 눌렀으면 되돌린다.** 팝업 `⋯` 또는 고른 뒤 나오는 [되돌리기], 웹 화면의 `⋯ → 한 단계 되돌리기`.
되돌리면 '오늘 확인함' 도 지워져 팝업이 다시 묻는다. 모든 변경은 **변경 기록**(웹 `⋯ → 변경 기록`, 이력 → 변경 기록)에
언제·어디서(팝업/웹/보드) 무엇을 했는지 남는다.

### 웹 화면

| 화면 | 내용 |
|---|---|
| 받은 알림 | 알림일이 지난 처리할 건 카드, 자료 경고, 오래 밀린 건 |
| 이번 달 | 기한이 이 달에 드는 건. 남은 건(기한 지난 건 맨 위)·지난 건, 합계, 엑셀 내려받기 |
| 연간 | 그 해 전체. 월·기관·상태·검색으로 거르기, 엑셀 내려받기 |

집계 낱말은 두 화면이 같다: **진행중** = 한 단계라도 밟은 건, **진행예정** = 아직 안 밟은 건, **기한 지남** = 기한이 지난 미완료.
추적 시작일 이전 건은 할 일이 아니므로 집계에서 빼고 '지난 건' 에 흐리게 보여 준다.
| 이력 | 기간별 처리 완료 건과 합계, 변경 기록, 검색 결과 엑셀 내려받기 |
| 항목 관리 | 항목 추가·수정·삭제·순서. 지워도 진행 기록·금액·증빙은 남는다 |
| 설정 | 추적 시작일, 공휴일 인증키·갱신, 백업, 프로그램 정보 |

1분마다, 그리고 창으로 돌아올 때 자료를 다시 읽는다. 오른쪽 위 달 모양 단추로 어두운 화면.

### 금액

- **금액규칙** 은 두 가지다. **고정** = 매년 같은 금액을 항목에 넣는다. **변동** = 해마다 그 해 금액을 넣는다.
  제출만 흐름은 금액이 없다.
- 금액을 모르는 건은 화면에 파란 **미확인 · 입력** 이 보인다. 누르면 그 자리에서 넣는다.
- 분할납부는 `⋯ → 회차 금액 한 번에` — 안내문 한 장의 회차 금액을 한 표에 넣고 합계를 대조한다. 나눠 채우지 않는다.
- 금액은 고지서·통보문·신고서를 보고 **직접 입력**한다. 받은 문서는 '받은 문서' 에 첨부해 두면 금액 창 옆에서 바로 열 수 있다.

### 받은 문서와 증빙

- **받은 문서** = 고지서·통보문처럼 받은 것. **증빙** = 신고서·영수증처럼 처리 후 붙인 것.
- 첨부하면 원본을 복사해 `data\증빙\{연도}\{id}\` 에 보관한다. 원본을 옮기거나 지워도 남는다.
- PDF·이미지는 웹 창 안에서 바로 보고, xlsx·hwp 는 이 PC 의 기본 프로그램으로 연다.

### 공휴일

`data\holidays.tsv` 에 2025~2027년 공휴일이 들어 있어 처음 켤 때 자료에 넣는다.
그 뒤는 웹 **설정 → 공휴일** 에서 [공공데이터포털](https://www.data.go.kr) 인증키를 넣고 **지금 공휴일 받기**.
인증키는 '한국천문연구원_특일 정보' 활용신청을 한 키여야 한다. 팝업도 30일마다 자동 갱신을 시도한다.
자료가 없는 연도는 주말만 반영하고 **알림을 이틀 앞당기며** 경고를 띄운다.

## 자료와 백업

| 파일 | 위치 | 설명 |
|---|---|---|
| 자료 DB | `data\납부알림.db` | 항목·진행·금액·증빙 목록·공휴일·변경 기록 전부 |
| 증빙 원본 | `data\증빙\` | 첨부한 파일 사본 |
| 실행 기록 | `data\run.log` | 1MB 넘으면 `run.1.log`…`run.3.log` 로 밀려난다 |
| 공휴일 인증키 | `data\apikey.txt` | 설정 화면에서 넣는다 |
| 백업 | `data\backups\` | 하루 첫 실행에 `납부알림-날짜.db`, 최근 30개 |

- 자료 폴더를 옮기려면 실행 파일 옆 `data-folder.txt` 에 경로를 한 줄 적는다.
- 백업을 다른 디스크에 두려면 실행 파일 옆 `backup-folder.txt` 에 경로를 한 줄 적는다 (권장).
- 설정 화면에서 **지금 백업**, 자료 파일 무결성 점검 결과를 볼 수 있다.

**백업에서 되살리기**: 팝업·웹 화면·보드를 모두 끄고(알림 영역 아이콘 → 끄기), `data\납부알림.db` 와
`납부알림.db-wal`, `납부알림.db-shm` 을 다른 곳으로 옮긴 뒤, `backups\` 의 사본을 `data\납부알림.db` 로 복사한다.

프로그램을 새 판으로 바꾸면 자료 파일도 자동으로 새 판으로 옮겨지며, 그 전에 `backups\납부알림-v1-이관전-….db` 사본이 남는다.

## 문제 해결

| 증상 | 확인 |
|---|---|
| 팝업이 안 뜬다 | 오늘 알릴 건이 없으면 뜨지 않는다. `data\run.log` 의 '표시할 건 없음' 확인. 예약 작업 등록 여부 확인 |
| 웹 화면이 안 열린다 | 알림 영역 아이콘이 있는지, `check-env.bat` [15], 포트가 8317 이 아니면 `%TEMP%\PaymentAlert.web-port` |
| "다른 창에서 먼저 바뀌었습니다" | 팝업·웹에서 같은 건을 거의 동시에 눌렀다. 한 번만 반영됐으니 새로 고친 화면에서 다시 확인 |
| "자료 파일이 이 프로그램보다 새 버전" | 옛 exe 로 새 자료를 열었다. `build.bat` 으로 새로 빌드 |
| 공휴일 경고 | 설정 → 공휴일에서 인증키·갱신 |

## 개발

- `run-tests.bat` — 날짜 계산, 팝업, 자료 DB, 웹 서버, 운영 부품, (Node 가 있으면) 화면 규칙 테스트.
  연간 일정표가 함께 출력된다. `run-tests.bat 2027` 처럼 연도를 붙일 수 있다.
- 웹 화면 소스는 `jbam-web\` (Next.js + shadcn/ui). 고친 뒤 Node 가 있는 PC 에서 `build-web.bat` 을 실행하면
  화면 규칙 테스트 → 정적 빌드 → `web\` 복사까지 한다. `web\` 을 함께 커밋한다.
- 설계 결정은 `docs\adr\`, 사용자 판단을 기다리는 항목은 `docs\decisions-needed.md`, 미구현 조사는 `docs\production-gaps.md`.

## 외부에 올리지 않는 파일

`.gitignore` 로 제외되어 있다. 이 설정을 풀지 않는다.

| 파일 | 이유 |
|------|------|
| `*.db`, `data\backups\` | 사내 납부 일정·금액·진행 기록 전부 |
| `data\*.tsv` (예시 파일 제외) | 옛 판 자료 |
| `data\apikey.txt` | 공공데이터포털 인증키 |
| `data\run.log` | 실행 기록 |
| `증빙\`, `*.pdf`, `비용납부내역\` | 고지서·영수증 원본. 사업자등록번호·계좌번호 포함 |
| `data-folder.txt`, `backup-folder.txt` | PC 마다 다른 경로 |
| `*.xlsx` | 원본 자료 |
| `mockup-web*.html`, `design-*` | 실제 금액이 들어간 화면 시안 |
| `PaymentAlert.exe` | 빌드 산출물. 회사 PC 에서 직접 빌드한다 |

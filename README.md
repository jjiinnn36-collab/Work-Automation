# 정기 납부 기한 알림

정기적으로 납부·신고해야 하는 항목의 기한을 매일 감시하고, 기한 며칠 전에 팝업으로 알린다.
팝업은 표시된 모든 건을 처리해야 닫히며, 처리 전까지 매일 다시 뜬다.

목표는 **기한 누락 0건**이다. 실제 이체·송금은 하지 않는다.

---

## 설치

### 1단계 — 환경 확인 (최초 1회)

`check-env.bat` 을 더블클릭한다. 관리자 권한은 필요 없다.
바탕화면에 `env-check-result.txt` 가 생성되고 메모장으로 열린다.

| 항목 | 정상 | 문제일 때 |
|------|------|-----------|
| `[6] DOCS_EXEC_OK` | exe 생성·실행 가능 | AppLocker 등으로 차단됨 |
| `[7] WINFORMS_OK` | 팝업 GUI 가능 | GUI 사용 불가 |
| `[11] SCHTASKS_CREATE=OK` | 매일 자동 실행 등록 가능 | `[12]` 시작프로그램으로 대체 |
| `[13] HTTPS=REACHABLE` | 공휴일 자동 갱신 가능 | 공휴일 파일 수동 관리 |

이 파일은 시스템을 변경하지 않는다. 만든 임시 파일은 실행 후 모두 삭제한다.

### 2단계 — 납부 항목 입력

**`data/payment-master-template.xlsx` 를 열어 채운다.**
기관·비용명·기한 같은 구분값은 이미 들어 있으니 노란색 칸만 입력하면 된다.
진행흐름과 금액규칙은 드롭다운으로 고를 수 있고, 두 번째 시트에 작성 방법이 있다.

다 채웠으면 **`convert-excel.bat` 을 실행**한다.
`data/payment-master.tsv` 가 만들어지고 프로그램은 그 파일을 읽는다.

> 엑셀의 "다른 이름으로 저장 → 텍스트(탭으로 분리)" 는 쓰지 않는다.
> 한글이 CP949 로 저장되어 프로그램이 읽을 때 깨진다. `convert-excel.bat` 은 UTF-8 로 저장한다.

엑셀을 고친 뒤 변환을 잊으면 프로그램이 옛 자료로 계속 돈다.
그런 경우 팝업에 "엑셀 양식이 납부 자료보다 최신입니다" 경고가 뜬다.

메모장으로 `data/payment-master.tsv` 를 직접 편집해도 된다.
형식은 `data/payment-master.sample.tsv` 를 참고한다.

### 3단계 — 그 해 실제 금액 (선택)

고지서·통보문을 받아 금액이 확정되면 `data/amounts.tsv` 에 적는다.
팝업에 실제 금액이 표시되고, 없으면 `금액 미확인 (고지수령)` 처럼 규칙만 표시된다.

```
연도	id	금액	출처	확인일	비고
2026	fss-03	3676250	감독분담금 부과액 통보	2026-03-11	1회차
```

**부가가치세 납부서는 자동으로 읽을 수 있다.**
PDF 파일을 `import-notice.bat` 위로 끌어다 놓으면 납부기한과 금액을 판독해
확인을 거친 뒤 `data/amounts.tsv` 에 반영한다.

판독한 금액은 **세목 합계와 문서상 '계' 를 대조**해 일치할 때만 채택한다.
어긋나면 반영하지 않고 직접 입력하라고 안내한다. 금액을 잘못 넣는 것보다 안 넣는 편이 낫다.

감독분담금 통보문과 금융투자협회비 안내문은 **스캔 문서라 자동 판독하지 않는다.**
텍스트를 뽑아보면 `17,514,266` 이 `17514266` 으로, `'26.10.20` 이 `'26.1020` 으로 읽힌다.
콤마와 마침표가 사라지는 수준이라 금액·날짜를 신뢰할 수 없다. 이런 문서는 직접 입력한다.

마스터의 `고정금액` 과 다르다. 마스터는 **매년 반복되는 정의**라 거기에 올해 금액을 넣으면
내년에도 올해 금액이 그대로 표시된다. 금액은 해마다 달라지므로 연도를 키에 포함해 따로 관리한다.

이 파일이 없어도 프로그램은 정상 동작한다. 금액을 몰라서 알림이 멈추는 일은 없다.
형식은 `data/amounts.sample.tsv` 를 참고한다.

### 4단계 — 공휴일 자료

`data/holidays.tsv` 에 **2025~2027년 공휴일 66건이 이미 채워져 있다.** 그대로 쓰면 된다.
한국천문연구원 특일정보 API에서 받아온 공식 자료이며, 대체공휴일과
2026년부터 부활한 제헌절, 2026년부터 공휴일이 된 노동절까지 반영되어 있다.

**2028년 이후**에는 갱신이 필요하다.

- **직접 입력** — `data/holidays.tsv` 에 `날짜<탭>명칭` 형식으로 추가한다. 연 1회면 충분하다.
- **자동 갱신** — [공공데이터포털](https://www.data.go.kr) 인증키를 `data/apikey.txt` 에 저장하면
  30일마다 자동으로 받아온다.

  인증키는 계정당 하나지만 **API마다 활용신청을 따로 해야 그 키가 동작한다.**
  data.go.kr 로그인 → *한국천문연구원_특일 정보* → 활용신청(자동승인) →
  마이페이지 → 오픈API → 개발계정에서 *승인* 확인. 반영에 시간이 걸릴 수 있다.

일상 실행은 캐시만 읽으므로 네트워크에 의존하지 않는다. API 호출이 실패해도 정상 동작한다.
사내에서 API가 차단되어 있으면 파일을 직접 채워도 된다.

자료가 없는 연도는 주말만 반영해 계산하고 **알림을 이틀 앞당기며** 팝업에 경고를 띄운다.
공휴일을 모르면 알림이 늦어질 수 있어 안전한 쪽으로 기울인 것이다.

임시공휴일이 새로 생기면 그 줄만 추가한다.

### 5단계 — 빌드

`build.bat` 을 더블클릭하면 exe가 만들어진다. 별도 설치는 필요 없다.

빌드 후 알림 팝업을 직접 띄워보려면 `start-alert.bat` 을 더블클릭한다.

> PowerShell 에서 `PaymentAlert.exe` 라고만 치면
> "실행할 수 있는 프로그램 이름으로 인식되지 않습니다" 오류가 난다.
> PowerShell 은 현재 폴더를 자동으로 뒤지지 않기 때문이다. `.\PaymentAlert.exe` 처럼
> `.\` 를 붙이거나, `start-alert.bat` 을 쓰면 된다.

`run-tests.bat` 을 실행하면 날짜 계산이 맞는지 확인할 수 있다.
연간 일정표가 함께 출력되므로 눈으로 검산해 볼 수 있다.
다른 연도는 `run-tests.bat 2027` 처럼 연도를 붙인다.

### 6단계 — 당월 기한 보드 (선택)

화면 한켠에 **이번 달 기한 목록을 상시 띄워두는 창**이다.
매일 뜨는 알림 팝업과 달리 처리를 강제하지 않는다. 보기만 하는 창이다.

- `start-board.bat` — 지금 바로 띄운다
- `install-board.bat` — 로그온할 때마다 자동으로 띄운다

표시 내용은 이번 달에 기한이 오는 건의 날짜·요일·비용명·**금액**·D-day·현재 단계다.
맨 위에 그 달 **합계**가 나온다.

기한이 지났는데 미완료면 빨간색, 3영업일 이내면 주황색, 완료면 회색으로 보인다.
금액을 아직 모르는 건은 `미확인` 으로 표시하고 합계에서 뺀 뒤 몇 건인지 알려준다.
빈칸으로 두면 0원으로 오해하기 때문이다. 납부가 없는 건(산정자료 제출 등)은 비워 둔다.

- 항상 위에 뜨고 작업표시줄에는 나오지 않는다. 끌어서 옮기면 위치와 크기를 기억한다.
- 10분마다 자료를 다시 읽는다. 팝업에서 단계를 진행하면 곧 반영된다.
- 항목을 두 번 누르면 그 건의 증빙 폴더가 열린다.
- 항목을 **오른쪽 클릭하면 이전 단계로 되돌릴 수 있다.** 확인을 한 번 받는다.
- 다른 달을 보려면 `PaymentAlert.exe --board --date=2026-06-01` 처럼 날짜를 준다.

**기준은 원기한이다.** 5/31이 일요일이어서 실제 납부가 6/1이어도 그 건은 5월 목록에 나온다.
제도상 기한이 속한 달로 묶는다.

밀린 건은 `일 → 06/01(월)` 처럼 **실제 납부일을 함께 표시**한다.
원기한 그날에는 납부가 불가능하므로 이 정보가 빠지면 안 된다.
D-day 는 실제 납부일까지의 영업일 수로 센다.

### 7단계 — 자동 실행 등록

`install-task.bat` 을 실행하면 매일 오전 9시에 자동 실행되도록 등록된다.
PC가 꺼져 있어 실행을 놓친 날은 켜진 뒤 곧바로 실행된다.

작업 스케줄러 등록이 막혀 있으면 시작프로그램 등록으로 자동 대체된다.
그것도 막히면 안내가 나오고, 그때는 `PaymentAlert.exe` 를 직접 실행해 쓴다.

해제: `schtasks /delete /tn "납부기한알림" /f`

## 사용법

### 진행흐름

항목마다 거쳐야 하는 단계가 다르다.

| 진행흐름 | 단계 | 해당 항목 |
|---------|------|----------|
| `신고납부` | 신고 전 → 신고완료 → 전표결재 → 납부완료 | 신고 후 납부하는 세목 |
| `납부만` | 납부 전 → 전표결재 → 납부완료 | 고지서를 받아 납부만 하는 건 |
| `제출만` | 제출 전 → 제출완료 | 산정자료 제출처럼 납부가 없는 건 |

진행 상황은 `data/status.tsv` 에 기록된다.

**잘못 눌렀으면 되돌릴 수 있다.**
- 그날 팝업 안에서는 [되돌리기] 버튼으로
- 그 뒤에는 보드에서 항목을 오른쪽 클릭해서

납부완료로 잘못 표시하면 팝업에 더는 뜨지 않아 프로그램이 조용해진다.
그 상태로 기한이 지나가는 것이 가장 위험하므로 되돌릴 길을 열어 두었다.
되돌리면 '오늘 확인함' 표시도 함께 지워져 팝업이 다시 물어본다.

팝업과 보드가 동시에 떠 있어도 서로의 변경을 지우지 않는다.
저장할 때 파일을 다시 읽어 실제로 바꾼 기록만 덮어쓴다.

`전표결재` 단계는 ERP에 자동으로 상신하지 않는다. 결재를 올렸는지 여부를 표시만 한다.

### 증빙 첨부

각 건마다 **[증빙 첨부]** 버튼이 있다. 신고서, 납부 영수증, 통보문 등을 붙여 둘 수 있다.

- 첨부하면 **그 시점의 단계로 기록된다.** 신고완료 상태에서 붙이면 신고서 증빙,
  납부완료 상태에서 붙이면 납부 증빙이 된다. 여러 개를 한 번에 골라도 된다.
- 원본을 복사해 `증빙/{연도}/{id}/` 아래에 보관한다.
  원본을 나중에 옮기거나 지워도 증빙은 남는다.
- **[증빙 열기]** 를 누르면 그 건의 증빙 폴더가 탐색기로 열린다.
- 첨부는 선택이다. 없어도 단계는 진행된다.

목록은 `data/attachments.tsv` 에, 실제 파일은 `증빙/` 폴더에 있다. 둘 다 저장소에 올라가지 않는다.

### 팝업 닫기

표시된 **모든** 건에 대해 아래 둘 중 하나를 선택해야 닫힌다.

- **[다음 단계]** — 다음 단계로 넘어간다
- **[오늘은 대기]** — 오늘은 할 게 없다 (결재 승인 대기 등). 내일 다시 뜬다

창 닫기(X)나 Alt+F4로는 닫히지 않는다. 매일 모든 건을 한 번씩 확인하게 하기 위해서다.

납부완료·제출완료까지 끝낸 건은 **그날 목록에는 완료 표시로 남고** 다음 날부터 뜨지 않는다.
잘못 눌렀으면 그 자리에서 [되돌리기]를 누른다.

같은 날 프로그램을 다시 실행해도 이미 처리한 건은 다시 묻지 않는다.

### 알림 시점 바꾸기

`알림영업일` 열의 숫자만 고친다. 기본은 3영업일 전이고, 비워두면 3이 적용된다.

| 항목 성격 | 알림 |
|----------|------|
| 금액을 직접 산정해야 하는 건 | **5영업일 전** |
| 고지서를 받아 그대로 납부하는 건 | 3영업일 전 |

항목마다 알림일이 다르므로 여러 건이 같은 날 겹칠 수 있다.
그런 날은 팝업에 목록으로 함께 표시되고, 건별로 따로 처리한다.

### 기한이 지난 건

기한이 지나도 **5영업일까지는** 계속 강제로 뜬다. 그 뒤로는 팝업 위쪽에 요약 한 줄로만
표시되고 처리를 강제하지 않는다. 전체 목록은 `data/run.log` 에 남는다.

이미 늦은 건을 매일 붙잡아도 얻는 게 없고, 그러다 프로그램을 꺼버리면
앞으로의 기한까지 놓치기 때문이다.

## 파일 형식

### data/payment-master.tsv

| 열 | 설명 |
|----|------|
| `id` | 항목 식별자. 겹치지 않게 |
| `기관` | 금융투자협회, 국세청 등. 한 행이 한 건이므로 매 행 채운다 |
| `비용명` | 부가세, 감독분담금 등 |
| `진행흐름` | `신고납부` / `납부만` / `제출만` |
| `월` | 1~12 |
| `일` | 날짜 숫자, 또는 말일이면 `EOM` |
| `알림영업일` | 기한 며칠 전에 알릴지. 비우면 `3` |
| `금액규칙` | `고정` / `고지수령` / `전기확정÷4` / `수작업` / `해당없음` |
| `고정금액` | `금액규칙`이 `고정`일 때만 입력 |
| `비고` | 메모 |

`EOM`(말일)을 쓰면 2월이 윤년인지 자동으로 판단한다.
`28` 로 고정하면 윤년마다 하루씩 어긋나므로 말일 기한은 반드시 `EOM` 으로 적는다.

기한일이 토·일·공휴일이면 **다음 영업일**로 자동 보정된다.

### data/amounts.tsv

| 열 | 설명 |
|----|------|
| `연도` | 4자리 연도 |
| `id` | 마스터의 `id` 와 같은 값 |
| `금액` | 숫자. 쉼표가 있어도 된다 |
| `출처` | 어느 문서에서 확인했는지 |
| `확인일` | 문서 수령일 등 |
| `비고` | 메모 |

## 외부에 올리지 않는 파일

아래는 `.gitignore` 로 제외되어 있다. 이 설정을 풀지 않는다.

| 파일 | 이유 |
|------|------|
| `data/payment-master.tsv` | 사내 납부 일정 |
| `data/amounts.tsv` | 실제 납부금액 |
| `data/apikey.txt` | 공공데이터포털 인증키 |
| `data/status.tsv`, `data/run.log` | 진행 이력 |
| `비용납부내역/`, `*.pdf` | 고지서·통보문. 사업자등록번호·가상계좌번호 포함 |
| `data/attachments.tsv`, `증빙/` | 첨부한 신고서·영수증 원본 |
| `data/board-position.txt` | 보드 창 위치 |
| `*.xlsx` | 원본 자료 (입력 양식만 예외로 포함) |
| `PaymentAlert.exe` | 빌드 산출물. 회사 PC에서 직접 빌드한다 |

납부 기한 알림 · 처음 설치

첫 실행 순서 안내

프로그램을 처음 켠 뒤, 쓸 수 있는 상태가 될 때까지의 과정입니다. Windows·macOS를 나눠 정리했습니다. 두 경우 모두 자료는 이 PC 밖으로 나가지 않습니다.

자동 — 프로그램이 알아서 함 직접 — 사용자가 누르거나 입력 인증키 — 공휴일 자동 받기용 (없으면 나중에 넣어도 됨)
🪟

Windows

누르는 파일: 시작하기.bat 또는 PaymentAlert.exe
준비물: 없음 — .NET Framework 4는 Windows 10·11에 기본 포함
  1. 폴더·자료파일 자동 생성 자동
    data 폴더와 빈 자료파일(DB)을 스스로 만듭니다.
  2. 인증키 창이 먼저 뜸 인증키
    실행하자마자 별도 팝업 창이 뜹니다. 인증키를 붙여넣고 [입력하고 받기].
    실제 화면 — 공휴일 자료 받기 · 처음 한 번
    공휴일 자료 받기 — 처음 한 번
    주말·공휴일을 반영해 기한을 계산하려면 인증키가 필요합니다.
    공공데이터포털에서 인증키 받기 (특일 정보)
    인증키
    나중에입력하고 받기
  3. 공휴일 자동 다운로드 자동
    "공휴일 자료를 받았습니다" 알림 → [확인]. (다음 실행부터 인증키 창은 안 뜸)
  4. 정리 화면에서 항목 추가 직접
    start-web.bat 실행 → 브라우저에 보드 열림 → [항목 관리]에서 기관·비용·기한 입력.
🍎

macOS

누르는 파일: 정리화면 열기.command (더블클릭)
준비물: Node.js 24 설치 · 처음 한 번 chmod +x mac/*.command
  1. 서버 시작 자동
    터미널 창이 잠깐 뜨고 정리 화면 서버가 켜집니다.
  2. 폴더·자료파일 자동 생성 자동
    data·증빙·backups 폴더와 빈 자료파일(DB)을 스스로 만듭니다.
  3. 브라우저에 정리 화면 열림 자동
    상단에 "자료 확인이 필요합니다 · 공휴일 자료 없음" 배너가 보입니다. 인증키 창은 뜨지 않습니다.
  4. 설정 화면에서 인증키 입력 인증키
    별도 창이 아니라 [설정] 탭 안에서 넣습니다: 인증키 입력 → [저장] → [지금 공휴일 받기].
    실제 화면 — 설정 탭의 공휴일 영역
    ⚠ 자료 확인이 필요합니다 — 공휴일 자료가 없습니다. 설정에서 인증키를 넣으세요.
    저장
    ⟳ 지금 공휴일 받기
  5. 정리 화면에서 항목 추가 직접
    [항목 관리]에서 기관·비용·기한 입력. 차입금 이자는 ERP 엑셀을 올리면 됩니다.
  6. 매일 알림 켜기 직접
    자동알림 켜기.command 더블클릭 → 매일 아침 9시에 알림 팝업 등록.
Windows

인증키는 실행 즉시 별도 창

프로그램을 켜면 인증키 팝업이 가장 먼저 뜹니다. 여기서 바로 넣거나 "나중에".

macOS

인증키는 설정 화면 안에서

별도 팝업이 없습니다. 정리 화면 [설정] 탭에서 넣습니다. 나머지 흐름은 동일합니다.

공통 — 인증키는 나중에 넣어도 됩니다(그동안은 주말만 반영). 자료·증빙은 이 PC의 data 폴더 안에만 있고, 공휴일 받기만 공공데이터포털에 연결합니다. 기존 자료를 옮기려면 data 폴더째 복사하면 됩니다.

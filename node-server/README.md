# 납부 기한 알림 — 맥·리눅스 겸용 판 (node-server)

윈도우 프로그램(`PaymentAlert.exe`)은 **그대로 두고**, 맥·리눅스에서도 같은 자료로
정리 화면과 알림을 쓸 수 있게 만든 판입니다. **추가 설치·서명·공증이 필요 없습니다.**
Node.js 하나만 있으면 됩니다(추가 라이브러리 없이 Node 내장 기능만 씁니다).

- 자료는 이 PC 밖으로 나가지 않습니다. 서버는 `localhost` 로만 받습니다(다른 PC 에서 닿지 않음).
- 윈도우에서 쓰던 `납부알림.db` 를 **그대로** 읽고 씁니다(자료 변환 필요 없음).
- 화면·계산·기록 규칙이 윈도우 판과 같습니다(모든 API 응답이 윈도우 서버와 일치하는지 검증함).

## 필요한 것

- **Node.js 24 이상** (권장). <https://nodejs.org> 에서 LTS 를 받으면 됩니다.
  - Node 는 `node:sqlite` 를 내장하고 있어 추가 설치가 없습니다.
  - Node 22~23 에서는 실행할 때 `--experimental-sqlite` 플래그가 필요할 수 있습니다. Node 24 를 권장합니다.

## 폴더

```
node-server/
  server.js          정리 화면 서버 (읽기·쓰기 전부)
  bin/popup-open.js  알림 팝업을 브라우저 앱 창으로 띄우는 실행기
  lib/               계산·자료 처리 (윈도우 C# 코드를 옮긴 것)
  popup/popup.html   알림 팝업 화면
  web/               정리 화면(정적 파일) — 윈도우 판 web 폴더를 그대로 두세요
  mac/               맥용 더블클릭 실행 파일(.command)
```

> `web/` 폴더는 이 저장소의 빌드된 `web/` 를 복사해 넣거나, `--web` 로 경로를 지정하세요.

## 자료 폴더

기본값은 `node-server/../data` (윈도우 판과 같은 규칙)입니다.
윈도우에서 쓰던 자료를 그대로 쓰려면 그 `data` 폴더(안에 `납부알림.db`)를 지정하세요.

```bash
node server.js --data "/경로/data" --web "/경로/web"
```

- `--data <폴더>` : 자료 폴더 (없으면 `../data`)
- `--web <폴더>`  : 정리 화면 정적 파일 폴더 (없으면 `../web`)
- `--port <번호>` : 포트 (없으면 8317, 사용 중이면 다음 빈 포트)
- `PA_PORT` 환경변수로도 포트를 정할 수 있습니다.

## 맥에서 쓰기 (더블클릭)

`mac/` 안의 파일을 처음 한 번 실행 권한을 준 뒤 더블클릭하세요.

```bash
chmod +x mac/*.command bin/popup-open.js
```

- **정리화면 열기.command** — 서버를 켜고 기본 브라우저로 정리 화면을 엽니다.
- **알림 지금 보기.command** — 알림 팝업을 앱 창으로 지금 띄웁니다.
- **자동알림 켜기.command** — 매일 아침 9시에 알림 팝업이 뜨도록 등록합니다(로그인 상태에서).
  - 시각을 바꾸려면 터미널에서 `mac/자동알림\ 켜기.command 8` 처럼 시(hour)를 넘기세요.
- **자동알림 끄기.command** — 자동 알림을 끕니다.

> 처음 `.command` 를 열면 맥이 "확인되지 않은 개발자" 경고를 낼 수 있습니다.
> Finder 에서 파일을 **오른쪽 클릭 → 열기** 로 한 번 허용하면 다음부터는 바로 열립니다.

## 알림 팝업

- 크롬·엣지가 있으면 주소창 없는 **앱 창**(`--app`)으로, 없으면 기본 브라우저 새 창으로 뜹니다.
- 윈도우 팝업과 같은 모양·동작입니다: 한 건씩 넘기기(`‹ ›`·`← →`), 위치 점, 슬라이드,
  헤더 `▾` 로 **제목 줄만 남기고 접기**, `⚙`/`⋯` 로 **정리 화면(항목 관리·설정) 열기**.
- 창을 **화면 오른쪽 아래 바닥**에 작게(약 360×264) 자동 배치합니다. 화면 크기는 OS 기본 도구로
  알아냅니다(맥 `osascript`, 리눅스 `xdpyinfo`). 못 구하면 브라우저 기본 위치로 뜹니다.
- 제목 바 색을 팝업과 같은 흰색으로 맞춰(`theme-color`) 회색 바 없이 **신호등 점만** 보이게 했습니다.
  신호등(닫기/최소화/전체화면)은 맥 OS 가 그리는 것이라 브라우저만으로는 완전히 없앨 수 없습니다.
- 윈도우 판의 항상-위(always-on-top)는 브라우저 창이라 그대로는 안 됩니다. 대신 창을 작게 띄우고,
  처리할 건이 없으면 **창을 열지 않습니다**. 노랑 버튼을 누르면 맥 기본대로 **독으로 최소화**됩니다.

## 리눅스

`bin/popup-open.js` 는 `google-chrome`/`chromium` 이 있으면 앱 창, 없으면 `xdg-open` 을 씁니다.
자동 실행은 cron 이나 systemd user timer 로 `node bin/popup-open.js` 를 아침에 부르면 됩니다.

## 안전

- 서버는 `127.0.0.1` 에만 바인딩합니다. `Host`·`Origin` 검사, 쓰기 요청의 `X-PaymentAlert` 머리글 검사를
  윈도우 판과 똑같이 합니다.
- 백업 폴더는 네트워크·클라우드 동기화 폴더를 막습니다(사본이 PC 밖으로 나가지 않게).
- 공휴일 자동 받기만 공공데이터포털(apis.data.go.kr)에 연결합니다. 그 밖에는 어디에도 보내지 않습니다.
